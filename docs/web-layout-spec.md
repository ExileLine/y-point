# Y-Point 全局布局方案（W0 第一步）

## 页面骨架

```text
桌面 >= 768px
┌──────────── 主导航 240px ────────────┬──────────────────── 工作区 ────────────────────┐
│ 品牌标识                              │ 顶部栏 56px：导航折叠 + 所在分区                │
│ 工作区：对话、Agent                  ├────────────────────────────────────────────────┤
│ 管理：用户、模型与供应商              │ 页面标题 / 操作区                                │
│ 账户：个人设置                        │ 页面内容独立滚动；对话页后续加会话栏 264px      │
└──────────────────────────────────────┴────────────────────────────────────────────────┘

手机 < 768px
┌────────────────── 顶部栏 56px：导航按钮 + 字标 ──────────────────┐
│ 页面标题与内容；主导航从左侧抽屉打开；会话栏后续独立进入         │
└──────────────────────────────────────────────────────────────────┘
```

- 桌面主导航可折叠到 72px，保留图标；移动端使用 280px 抽屉。不同层级的导航与会话列表分开，避免业务操作挤在全局侧栏里。
- 普通管理页在工作区内使用最大宽度 1440px；对话页可使用全宽布局。页面标题在顶部栏下，内容区域允许独立滚动。首期导航分为工作区、管理、账户；未实现的页面当前禁用，不放可点击空壳。
- 本文记录已确认的 W0 骨架。随后第二步已将默认页面替换为 Agent 目录，并开始按该页面的实际功能接口建立交接表；对话、用户、模型、个人设置以及会话栏仍在对应阶段实现。

## 标识与主题

选择 `docs/logos.png` 第三排第一个方案，裁出 `web/public/brand-icon.png` 和 `web/public/brand-wordmark.png`。本阶段采用蓝色主操作、橙色辅助强调与冷灰中性色，变量见 `web/src/styles/design-tokens.css`。图片来自候选位图；用于正式发布前还需核对原始资源、透明背景和缩放清晰度。

## 2026-11-03 页面统一调整

品牌以用户指定的第三排第一个候选为准：深蓝与亮蓝 Y、橙色圆点及 Y-POINT 字标。右上角账户按钮使用该图标并保留用户名、账户名称和退出登录菜单；手机仅显示图标。原 W0 截图保留为历史记录，当前页面以本轮截图为准。

桌面顶部通过面包屑标明所在分区、页面和会话层级；导航品牌可返回 Agent 首页。提供键盘「跳转到主内容」入口。Agent、模型、Skill、Tool 统一页标题、用途说明、主操作与白色内容面板；Skill/Tool 在 768px 以下切换为卡片。会话保留左右分区和独立滚动，优化会话选中态、用户消息与输入区域。
