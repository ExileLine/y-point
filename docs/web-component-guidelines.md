# Y-Point 前端组件使用约定（开发准备）

此约定与 `web-design-tokens.css` 配套。W0 骨架已建立 `web/` 工程，tokens 镜像到 `web/src/styles/design-tokens.css` 并映射到 Ant Design `ConfigProvider.theme.token`。修改设计值时须同步两份文件；正式发布前确认裁切标识的原始资源。

| 场景 | 优先组件与规则 |
| --- | --- |
| 全局框架 | `Layout`、`Layout.Sider`、`Layout.Content`、`Menu`；移动端 `Drawer` 承载导航。页标题、工具栏和内容区保持固定层级。 |
| 页面切换 | 路由用于跨页面；`Tabs` 用于同一资源的子视图；`Segmented` 只用于卡片/表格等即时模式切换。 |
| 资源列表 | `Table` + `Pagination`，少量资源可用单层 `Card`/列表；`Input.Search`、`Select` 放在同一工具栏。移动宽表格在自身容器滚动或改成逐项摘要。 |
| 表单与设置 | `Form`、`Input`、`Select`、`InputNumber`、`Switch`、`Upload`；按服务端字段验证。创建/编辑优先 `Drawer`，短确认优先 `Modal` 或 `Popconfirm`。 |
| 状态与反馈 | 首屏 `Skeleton`/`Spin`，无资源 `Empty`，可恢复错误 `Alert`/`Result` + 重试，局部操作使用按钮 `loading`，结果用 `App.message`。不可把网络错误渲染成空数据。 |
| 对话与文件 | `Input.TextArea`、`Upload`、`Button`、`Tooltip`、`Tag`、`Alert`、`Drawer`；消息流布局可定制。Run 过程预览与最终消息分开，下载逐次走授权接口。 |
| 图标与辅助操作 | 使用 `lucide-react`；图标按钮必须有可访问名称，非显而易见的图标配 `Tooltip`。 |

组件不自造表格、分页、表单校验、开关、抽屉、确认框或通知的视觉样式。组件 CSS 中不直接写颜色、字号、间距、圆角或阴影数值，统一引用 `--yp-*`；固定尺寸也应有对应 token 或由布局约束计算。状态语义由服务端响应决定，前端禁用或隐藏操作不能替代鉴权。

视觉参照范围：Octop 的导航密度、标题到操作区的节奏、信息分组、筛选和空态层级。必须使用 Y-Point 自己的品牌色、文案、图标与文件；不复制 Octop 的源码和资源。Y-Point 的对话流程按 `README.md` 的 Agent 会话、Run、消息、事件、附件、产物关系实现；Octop 的聊天协议和功能入口不适用。

## 资源管理页统一约定（2026-11-03）

- `components/ResourcePage.tsx` 提供 `PageHeader`、`ResourceCollection`、`ResourceCard`。页标题包含用途说明和主要操作；列表筛选、结果数与刷新在内容面板内。
- Skill/Tool 桌面使用表格，手机使用带状态、版本与操作的卡片；二者共享筛选逻辑。仅超过 20 条时显示分页，不用整页横向滚动承载手机表格。
- 可见性、启停、待试运行分别表达。已停用 MCP 显示「已停用」，脚本未验证显示「待试运行」，不根据单一 enabled 推断验证状态。
- 列表请求失败显示错误与重试，已有数据可继续显示；不能将网络错误显示成空列表。编辑冲突显示面板内错误并保留输入；Skill 更新保留包内附加文件。
- 编辑抽屉宽度、代码字体、品牌缩放、焦点与触摸目标使用 tokens，减少动画遵循系统偏好并通过组件库主题控制；仍须保持完整服务端权限与版本检查。浏览器拦截回归属于前端契约证据，真实权限、执行环境和上游服务独立验收。

## 对话消息与标签（2026-11-03）

- 历史消息有数据时采用后台同步，不卸载消息列表或用骨架屏覆盖；流式和终态切换不得清空已有回复。滚动跟随取决于用户是否正在底部，向上阅读时保留位置。
- `MessageContent` 统一安全 Markdown/GFM 与代码高亮；`CopyButton` 复制消息原文，代码复制仅包含代码。HTML 源码按文本展示，避免引入 raw HTML 执行；表格/代码自身滚动，手机页面不产生横向溢出。
- `StreamingMessage` 只控制呈现进度，不改动 SSE 序号、快照恢复、最终消息和用量记录。遵循系统减少动画偏好。
- 状态色的文字、浅底和边框分别定义；能力配色与验证状态分别表达，禁止以颜色替代验证标记。两份设计变量同步维护。
