# M6 知识库与检索契约

本契约和 `tests/fixtures/m6_retrieval.json` 在业务实现前于 2026-11-03 固定。阈值不得按实现结果下调。M5.1 的现场验收继续保留；用户已授权直接启动 M6。

## 资源与授权

知识库默认私有，只允许所有者管理，通过指定用户共享授予只读查询。共享 Agent 不扩大知识库权限。Agent 保存知识库 ID，Run 在提交时保存当时可访问的已发布索引 ID。每次检索、引用读取和实际工具调用都重新核对当前权限、用户及资源删除状态；撤权与删除立即阻断新访问并请求取消相关运行，已经交付的历史消息不承诺从用户记忆或模型历史中撤回。

文档和上传版本独立，原始文件复用私有 Artifact/Blob 存储，知识文档不受普通附件的三十天到期策略影响。哈希仅在同一知识库的同一未删除文档上传版本内用于去重，不进行跨用户或跨库可观测去重。文档更新保存新版本，旧索引继续服务直到完整新代成功；删除文档立即从所有旧代结果中过滤。

索引代绑定完整文档版本清单、分块配置、检索模式、嵌入模型与实际维度。上传、更新、删除、重建或模式切换产生新代，只有最新期望代完整成功后可原子替换 active_index_id；旧代失败不破坏已发布索引。Run 固定代以保证引用可追溯，旧代仍受当前权限和逻辑删除约束。历史代保留到显式物理清理，不按缓存年龄淘汰仍被 Run 引用的数据。

## 接口与任务

`/api/v1/knowledge-bases` 提供 CRUD、指定共享、上传/更新/列举/删除文档、检索、重建和持久化任务进度、重试与取消。仅所有者可管理；未授权统一 404；并发版本冲突 409；超限 413/429；参数错误 400/422。`/api/v1/models/{id}/embedding-test` 独立探测嵌入能力，文本能力不能替代嵌入能力验证。

任务状态使用集中枚举：uploaded → parsing → chunking → embedding → indexing → completed，以及 failed/cancel_requested/cancelled。关键词模式明确跳过 embedding。数据库租约和 CAS 保证独立 worker 不重复发布；阶段持久化并更新租约，操作有总超时、最大尝试次数、批量与 Token/费用预算。过期任务有界重试，重试重新构建未发布代，不续写半成品。取消与失败清理半成品；正式发布一次事务同时写片段、原生全文索引、代状态和活动指针。上传 HTTP 只保存文件及调度意图，不执行解析或模型调用。

## 检索、引用与后端

中文预切分为稳定字符二元词，拉丁词及中文词编码成各数据库一致可索引的词项。SQLite 使用 FTS5，PostgreSQL 使用 simple 配置全文索引，MySQL 使用 FULLTEXT。向量默认使用有界精确余弦适配，PostgreSQL 可显式选择 pgvector；扩展不作为关键词或其他数据库启动依赖。向量索引和查询绑定同一模型及维度，输出校验数量、维度、有限数值、非零范数；超时、鉴权、限流和非法响应都脱敏。

关键词和向量分别产生候选后以 RRF（k=60）融合，可显式选择本地词项覆盖重排；不引入未选定的外部付费重排依赖。Top-K、候选数、片段字节和总响应字节均有界。先按当前授权限定索引、文档和候选，再执行排序/返回；完全无词项匹配且相似度低于阈值时返回 no_answer，不强迫模型编造。

命中包含 kb_id/index_id/document_id/document_version/chunk_id、原文件名、提取文本中的字符起止、页码/标题及原文摘要。引用指向固定片段并在读取时重新鉴权。规范化后的提取原文与 offset 子串必须完全相等；PDF 页码明确为实际页号，DOCX 无固定页码，使用段落/标题位置，不伪造页号。

Agent 使用现有 Tool Registry 注册 search_knowledge_base 只读工具，复用执行租约、预算、取消和事件；内容用结构化 untrusted 文档数据返回，不拼接进系统指令，提示模型只将检索文本当证据并引用固定标识，无答案明确说明。审计只保存 query_hash、固定代/片段引用、数量、耗时和用量，不向 SSE 写入查询和文档正文。

## 先验评测与验收

固定集中每份 TXT/Markdown 解析成功率 100%，六道中文问题关键词 Recall@3=100%，引用与规范提取原文一致率 100%，跨用户/撤权/删除泄漏为 0，两道无答案误命中为 0。PDF/DOCX 扩展验证标题、页码、表格、重复及长片段；扫描 PDF 返回 ocr_required，不发布空索引。混合检索至少不降低固定集 Recall@3；真实嵌入验证另记录模型/维度和结果，不将假向量用例作为上游验证。

覆盖双用户、共享 Agent、撤权、更新旧/新代、失败保留旧代、取消、超时、超限、进程重启/过期租约、三数据库迁移/回退重升、固定集和真实模型检索回答。未具备的浏览器、目标平台或具体后端场景保留未验收，不能以单个关键词闭环勾选 M6 总项。

设计选择为私有资源、不可变代与原子发布、检索前后鉴权和 RRF 融合。外部官方文档本轮未能在线获取，不将未核实的文档内容作为验收证据；具体协议与后端范围以 README 和实际测试为准。
