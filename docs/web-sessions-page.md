# Agent 会话与文本对话交接

会话入口位于 Agent 卡片、表格与详情，路由为 `/agents/{agent_id}/sessions`。桌面展示会话栏和消息区，手机在列表与当前会话间切换。所有者与被共享用户分别拥有自己的会话；共享用户读取的是 Agent 安全摘要。

| 操作 | 接口 | 前端处理 |
| --- | --- | --- |
| Agent 资料 | `GET /api/v1/agents/{id}`，共享时回退 `GET /api/v1/agents/shared/{id}` | 共享页不读取或显示系统指令；404 清除失效会话内容。 |
| 会话列表 | `GET /api/v1/agents/{id}/sessions?page=&page_size=20&archived=&search=` | 标题搜索、归档筛选和分页均由服务端执行。 |
| 新建与详情 | `POST /api/v1/agents/{id}/sessions`、`GET /api/v1/agents/{id}/sessions/{session_id}` | 新建后进入独立会话；刷新路由时重取会话。 |
| 重命名与归档 | `PUT /api/v1/agents/{id}/sessions/{session_id}` | 提交 `expected_version`；409 展示错误并刷新列表。归档后禁止发送。 |
| 删除 | `DELETE /api/v1/agents/{id}/sessions/{session_id}` | 确认后删除；运行中服务端拒绝并保留会话。 |
| 消息与 Run 恢复 | `GET .../messages?after=<message_id>&limit=100`、`GET .../runs?page=1&page_size=20` | 消息按 ID 逐页读取；页面刷新后找回仍在运行的 Run。 |
| 文本提交与状态 | `POST .../runs`、`GET /api/v1/runs/{run_id}`、`POST /api/v1/runs/{run_id}/cancel` | 每轮新 `request_key`；无法确认提交结果时保留完整请求供明确重试。已有对话因默认模型变更返回 409 时提供新建会话入口。只有 SSE 连接异常或超时才轮询状态，避免轮询先结束并关闭增量预览；完成后在后台重读会话消息，保留预览直到同 Run 的最终消息到达；失败或取消不把预览保留为最终消息。 |
| 运行中回答 | `GET /api/v1/runs/{run_id}/snapshot?after=<sequence>&limit=100`、`POST /api/v1/runs/{run_id}/stream-ticket`、`GET /api/v1/runs/{run_id}/stream?after=<sequence>` | 提交、刷新或断线后先逐页追平持久化事件，再用 Bearer 签发短期 HttpOnly 票据并以最新事件序号订阅 EventSource。按序号去重显示 `text_delta`；终态重读消息，产物发布事件触发消息刷新。 |
| 产物与附件下载 | `GET /api/v1/artifacts/{artifact_id}/download` | 从消息的 `attachments` / `artifacts` 获取 ID，逐次携带 Bearer；401 刷新后重试一次，失败回到登录。按服务端 `Content-Disposition` 文件名及原始 MIME/字节保存，HTML 仅下载；403/404 与网络失败显示提示，可重试。 |
| 调用名称与状态 | 消息中的 `calls`；`GET /api/v1/runs/{run_id}/calls` | 历史按页携带摘要；运行中监听 `tool_started/tool_completed/tool_failed` 后重读摘要并定时补齐。显示 Skill/Tool/知识库名称及成功、失败、执行中或结果未确认，不读取工具参数和结果。 |

本阶段接入文本发送、历史查看、快照追平、SSE 运行中预览及历史附件/产物授权下载；`GET /runs/{run_id}` 只在流不可用时查询状态，不提供回答正文。附件上传、审批和主动回答导出开关仍在 W3；历史附件和已发布产物显示文件卡片与授权下载按钮，不可用文件保留提示并禁用下载。Token/成本预算或明确文件交付要求会使服务端暂缓公开文本，直到相关校验通过。直接文本 `POST /runs` 不是会话入口。

`npm run verify:sessions` 以模拟接口验证创建、重命名、归档/恢复、删除、搜索、分页、发送、运行中 SSE 预览、状态接口抢先完成时仍保留流预览、断线快照续接和去重、最终消息、失败后同键重试、模型切换冲突引导、切换会话时忽略过期刷新响应、共享用户安全摘要及 1280×800/375×812 布局。`uv run pytest tests/test_agent_sessions.py -q` 覆盖服务端会话隔离与运行约束。真实账号、worker 与上游模型的完整浏览器联调尚未验收。

## 2026-11-03 对话体验与消息格式

发送成功、产物事件、手动刷新和 Run 终态只触发后台同步，已有消息与会话目录保持挂载。首次进入且没有历史数据时才显示骨架屏。原问题是同步每次都把历史区域替换为骨架屏、终态又提前卸载流式回复，导致内容高度塌缩和滚动跳动；`verify:chat` 已先复现旧实现的发送刷新失败，再验证修复。

消息区使用固定可视高度与独立滚动。初次进入和主动发送跟随最新内容；在底部时按内容增长跟随，向上阅读后保留位置，显示「回到最新消息」。手动刷新保持阅读位置；流式预览到最终消息之间持续显示同一轮回复，最终正文仍以服务端 messages 为准。

用户消息在右侧，助手消息在左侧。助手正文使用 Markdown/GFM：标题、强调、列表、任务列表、引用、分隔线、链接、表格、行内代码及语言代码块；代码块显示语言与复制按钮，整条消息可复制原文。完整 HTML 文档与有效 JSON 自动显示为源码块；HTML 不执行，未声明语言和未知语言回退为可读源码。表格和代码在自身区域横向滚动；外链使用新窗口和 noopener/noreferrer，远程 Markdown 图片展示为可点击链接。

流式文本仍按 SSE sequence 去重与快照追平，呈现层用 requestAnimationFrame 分帧平滑追加，按字素切分避免拆断 Emoji 和组合字符。积压时自适应追赶，完成后使用服务端最终正文；流式阶段不反复执行代码高亮，最终正文再高亮。系统偏好减少动态效果时直接显示已收到的文本。

新增 `npm run verify:chat`：桌面 1280px、手机 375px 的长历史、发送后台同步、阅读位置、终态衔接、分帧更新、左右布局、Markdown/HTML/JSON/未知语言、复制与安全渲染，以及减少动画设置。该脚本使用虚构拦截响应；真实模型流式节奏与真实账号/网络联调仍待验收。

## 消息操作栏（2026-11-04）

助手历史回复提供复制、重新生成、喜欢、不喜欢和分享五个纯图标按钮，悬停或键盘聚焦显示名称；用户消息提供复制，生成中预览与完成回复使用同一组五个图标按钮。代码复制同样仅显示图标。复制功能已实现，其余入口点击显示「功能待接入」，待后端契约交付后补齐，不记录虚假的反馈或分享状态。


## 产物与附件下载（2026-11-04）

助手消息 `artifacts` 与用户消息 `attachments` 使用 `MessageFiles` 文件卡片，展示文件名、来源、提供给模型的状态和可用性；下载按钮沿用纯图标、悬停/聚焦提示。不可用文件保留在历史中并禁止下载，下载中显示加载状态、防止重复请求，失败后恢复操作。只有服务端已发布到消息的文件才出现下载入口；正文中的文件名和模型声称生成完成不代表文件已发布。

点击后由 `downloadArtifact` 调用服务端授权接口，文件保留原始字节、MIME 与 UTF-8 文件名，不把文本或 JSON 重新序列化；缺少有效文件名时回退消息中的文件名。服务端仍逐次校验文件所有权及存储可用性；前端可用状态仅是展示依据。下载不切换页面、不重新提交 Run，也不执行 HTML。`artifact_published` 事件继续触发历史消息重读，Run 完成后延迟发布的回答 TXT 同样在发布后显示下载入口；主动导出开关及文件预览尚未接入。

新增 `npm run verify:artifacts`，通过桌面/手机浏览器真实下载事件读取文件并核对名称和字节，覆盖中文名、二进制、HTML/JSON、参考附件、重复点击、登录刷新、403/404、网络失败与重试、重读消息出现延迟产物及刷新凭证失败退出登录。此脚本使用虚构接口响应；本次用户提供的真实页面与服务端端口未启动，真实会话下载复验记录在 `y-point-web-todo.md` 的 W4.5。


## 调用名称与状态（2026-11-04）

`RunCalls` 在助手正文上方展示紧凑的本轮调用列表，显示类型图标、名称及状态。成功用绿色、失败用红色、执行中用蓝色、结果未确认用黄色，同时保留状态文字与图标。名称按内容换行，未调用资源时不显示空列表；同名的多次调用按 `call_id` 区分。知识库检索目标可能包含多个名称，服务端对当前不可访问的目标使用不可用提示。

历史从消息 `calls` 恢复；用户消息也携带所属运行摘要，在该轮没有最终助手消息时于助手一侧显示调用记录，不创建假的助手正文。运行中由 `ActiveRunCalls` 在文本增量到达前也可展示名称与状态；工具事件触发合并重读，定时同步作为补齐，切换会话时取消旧请求。读取错误保留已经确认的结果并显示重试，权限失效清空摘要。结果逐次取自服务端事件，不把整轮失败套用到所有调用，也不把无命中的成功检索标成失败。

`npm run verify:calls` 使用虚构接口，验证桌面和手机的历史与实时调用、SSE 更新、同名调用的独立结果、同步失败重试、无最终回答的失败轮次、长名称布局、最终消息衔接及刷新恢复。真实工具与模型联调状态见 `y-point-web-todo.md` W4.6；后端摘要与权限验证见 `y-point-server-todo.md`。
